## 2026-11-24 — Раунд 63: Узнаваемый индивидуальный звук для каждой бочки в бонго (дуэль и соло)

- Задача:
  - Пользователь попросил: «в бонго дуэле нужно изменить звуки - сделать каждой бочке свой узнаваемый звук».
- Анализ проблемы:
  - В `src/audio.js` звук `drum` был единой шаблонной формулой для всех 4 барабанов (`tone(f * 1.6, 0.25, { type: 'sine', slide: f }) + noise` с небольшим сдвигом базовой частоты 196, 262, 330, 440 Гц).
  - Все 4 бочки звучали монотонно и однородно как синтетический свип, не имея выразительного акустического характера и не позволяя легко отличать бочки на слух с закрытыми глазами.
- Решение и звуковой дизайн:
  - В соответствии с правилами скиллов `game-audio` и `ui-sound-design`, для каждой из 4 бочек синтезирован собственный, физически аутентичный перкуссионный тембр в своём музыкальном регистре с расстоянием примерно в октаву:
    1. **Бочка 0 (Красная / Deep Bass Conga / Tumbadora):**
       - Глубокий, плотный, бархатный басовый удар большой деревянной бочки.
       - Плотный спад 130 Гц → 55 Гц (чистый синус, 0.32 с) + тёплый треугольный панч 85 Гц → 48 Гц с lowpass-фильтром 280 Гц + низкочастотный шлепок мембраны (noise bandpass 340 Гц). Узнаваемый звук: «БУМ-М».
    2. **Бочка 1 (Жёлтая / Conga Slap / Mid Wood Tom):**
       - Упругий, сочный, хлёсткий шлепок ладони по туго натянутой коже деревянной конги.
       - Резонанс корпуса 300 Гц → 175 Гц (синус, 0.22 с) + деревянный обертон 460 Гц → 250 Гц (треугольник, фильтр 1400 Гц) + резкий свип шлепка (noise bandpass 1400 Гц → 750 Гц). Узнаваемый звук: «ПАХ / ТАП».
    3. **Бочка 2 (Зелёная / High Open Bongo / Quinto):**
       - Чистый, поющий, открытый высокий мелодичный бонго.
       - Открытый тон 480 Гц → 392 Гц с деликатным вибрато-шиммером корпуса (синус, 0.25 с) + гармонический октавный резонанс 960 Гц → 784 Гц (треугольник, 2200 Гц) + звонкий щелчок пальцев (noise 2800 Гц, Q=3.2). Узнаваемый звук: «ТЁН / ТУМ».
    4. **Бочка 3 (Синяя / Steel Rimshot / Timbale / Bright Ping):**
       - Острый, звенящий стальной римшот по металлическому ободу / тимбалес.
       - Звенящий обод 784 Гц → 700 Гц (square с обрезным фильтром 2600 Гц) + высокий кристальный гармонический пинг 1480 Гц → 1320 Гц + яркий металлический щелчок (noise highpass 6500 Гц, Q=3.5). Узнаваемый звук: «ЦОК / ТИНЬ».
