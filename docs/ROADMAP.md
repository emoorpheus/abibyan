# Что дальше с Абибяном (после Round 26)

## До 21.11 — чтобы подарок сработал (по порядку)

1. **Фраза и записки для «24 секретов».** Записки теперь под замком (Round 26): сборка шифрует их фразой, которую
   знает только Даша, а игра на первом найденном сердечке задаёт её вопрос. Нужно:
   - файл `~/.config/abibyan/phrase.txt` (вне репозитория, `chmod 600`): строки `вопрос: …`, `ответ: …` (2–3 слова),
     по желанию `подсказка: …` (покажется после 3 неверных ответов); проверка — `python3 tools/secret_box.py check`;
   - тексты в `docs/24-secrets.md` (можно не все 24), по желанию фото `assets/secrets/<номер>.jpg` (до ~200 КБ);
   - `python3 build.py` — если записки есть, а фразы нет, сборка остановится.
2. **Сайт — GitHub Pages** (`docs/PRIVATE_RELEASE.md`, 08.11). Репозиторий публичный, поэтому записки уходят туда
   только шифром; вопрос и подсказку видит любой, кто откроет сайт, — ответ должна знать только Даша.
   Публикация — только по твоей команде.
3. ~~**QR = настоящий адрес.**~~ Готово: QR ведёт на `emoorpheus.github.io/abibyan/`, с бумаги сканируется (ты
   проверил 08.11). Если адрес сменится — `python3 tools/card.py <адрес>`.
4. **Репетиция на твоём iPhone** — `…/test.html` (там всегда 21.11 и 100 000 монет):
   - «Поделиться → На экран Домой», запуск с иконки;
   - свечи в микрофон (Safari спросит разрешение) и пальцем;
   - звук: на iPhone Web Audio молчит, если включён беззвучный режим (переключатель сбоку) — проверь с выключенным;
   - найди 2–3 сердечка, закрой и открой игру — найденные остаются;
   - замок (если в сборке есть записки): вопрос на первом сердечке, клавиатура появилась, экран не прыгнул,
     верный ответ открыл записку;
