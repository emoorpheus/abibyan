# Абибян на GitHub Pages — бесплатно, по ссылке, с иконкой на телефоне

Ссылка будет такая: **https://emoorpheus.github.io/abibyan/**
(аккаунт `emoorpheus`, репозиторий `abibyan`). Это бесплатно и навсегда, реклам нет.
Чтобы сайт был «не для всех, а по ссылке» — см. **`docs/PRIVATE_RELEASE.md`** (коротко: в поиске его не будет и так).
Рядом — тестовая версия для репетиции: **https://emoorpheus.github.io/abibyan/test.html** (см. раздел 2).

Почему именно сайт, а не просто файл `abibyan.html`:
- **микрофон** (задувать свечки) телефон даёт только сайту с `https://` — у GitHub Pages он есть;
- «**На экран Домой**» — Абибян становится иконкой, открывается на весь экран, работает даже без интернета;
- сохранение живёт в её телефоне, ничего никуда не отправляется.

## 1. Загрузить (один раз, ~5 минут, с компьютера)

1. Зайди на **github.com** под `emoorpheus`.
2. Справа вверху **«+» → New repository**.
   - Repository name: **`abibyan`**
   - **Public** (для бесплатных Pages нужен публичный: сам сайт открывается только по ссылке и не попадает в поиск,
     но файлы репозитория — а в них и твои записки — увидит тот, кто зайдёт к тебе в профиль на GitHub.
     Чтобы спрятать и их — **Private** + один из способов в **`docs/PRIVATE_RELEASE.md`**.)
   - галочки «Add a README» и прочее — не нужны → **Create repository**.
   (Если репозиторий `abibyan` уже есть — просто открой его.)
3. На странице пустого репозитория нажми ссылку **«uploading an existing file»** (или **Add file → Upload files**).
4. Распакуй `dist/moy-abibyan-site.zip` у себя на компьютере и **перетащи все файлы из него** (не папку целиком) в окно:
   `index.html`, `test.html`, `voice1.txt`, `voice2.txt`, `sw.js`, `manifest.webmanifest`, иконки `*.png`
   (и `.nojekyll`, если видно — он не обязателен). Внизу **Commit changes**.
5. **Settings → Pages** (меню слева). В «Build and deployment»:
   - Source: **Deploy from a branch**
   - Branch: **main**, папка **/ (root)** → **Save**.
6. Подожди 1–3 минуты и обнови страницу Settings → Pages: сверху появится
   «Your site is live at **https://emoorpheus.github.io/abibyan/**».

## 2. Репетиция 21 ноября — у себя, с деньгами (можно и нужно)

Открой на **своём** iPhone в Safari: **https://emoorpheus.github.io/abibyan/test.html**

- Это тестовая версия: для неё **сегодня 21.11.2026** (время суток настоящее), 100 000 монет и всё открыто.
- У неё **своё сохранение** — настоящая игра (и у тебя, и у неё) не трогается.
- Сразу будет коробка «Дашулик, это тебе!» → постучи → Абибян выпрыгнет → сам начнётся праздник: зал украшен,
  друзья, торт с 24 свечками. Нажми «Подуть» → «Разрешить» → подуй на телефон, как на свечки. Потом подарки и фото.
- **Ещё раз с самого начала:** Настройки (шестерёнка) → **«Начать репетицию заново»** — снова коробка и праздник.
  Или открой ссылку с `#fresh` на конце: `…/abibyan/test.html#fresh`.
- После праздника там же можно поискать сердечки (в тестовой версии вместо твоих записок — образцы).

Если свечки не гаснут от дутья — напиши мне, как именно было (сколько горит, шевелятся ли огоньки), подстрою.

Ещё вариант — репетиция в настоящей игре на любом телефоне: **https://emoorpheus.github.io/abibyan/#bday**
(ничего не засчитывает: настоящий праздник 21.11 всё равно будет).

Настоящую ссылку (без `test.html`) открой у себя, если хочешь, — у тебя будет своя коробка, сохранение у каждого
телефона своё. Праздник с тортом до 21.11 там сам не начнётся.

**Не открывай ссылку на её телефоне до 21 ноября** — коробку она должна открыть сама. И не давай ей `test.html`.

## 3. В день рождения — на её iPhone

1. Камера → QR-код на открытке (`dist/abibyan-card.pdf`) → открыть в **Safari**.
2. **Сначала** «Поделиться» → **«На экран „Домой“»** → Добавить.
   (У Safari и у иконки на iPhone *разные* сохранения — поэтому играть лучше сразу с иконки.)
3. Открыть Абибяна **с иконки** → постучать по коробке.
4. Когда друзья принесут торт: «Подуть» → телефон спросит про **микрофон** → «Разрешить» → дуть на свечки.
   Если микрофон не разрешить или он не сработает — кнопка «Пальцем»: свечки тушатся касанием.
5. Потом Абибян скажет, что спрятал сердечко с секретом. Сердечки — по одному: нашла одно → читает записку →
   он прячет следующее в другой комнате. Если долго не находит — он подсказывает «Тепло» / «Холодно».

Честно: задувание проверено на компьютере с тестовыми записями (дутьё, тихое дутьё, «фу-у-у» — тушат; речь, голос,
музыка, хлопки, тишина — нет). На настоящем iPhone — проверь репетицией (`test.html`, см. выше).

## 4. Обновить (например, когда впишешь 24 секрета)

1. Тексты — в `docs/24-secrets.md`, картинки — `assets/secrets/<номер>.jpg`, потом `python3 build.py`
   (или пришли файл мне — соберу сам).
2. На GitHub в репозитории: **Add file → Upload files** → перетащи новые `index.html` и `test.html` (и `voice*.txt`, `sw.js`,
   если менялись — проще всего снова все файлы из `dist/moy-abibyan-site.zip`) → **Commit changes**. Старые файлы заменятся.
3. Через ~10 минут обновление доедет; у неё Абибян обновится при следующем открытии (иногда нужно закрыть и открыть
   ещё раз). Сохранение, найденные сердечки и фото в альбоме не теряются.
