# Выпустить Абибяна «не для всех, а по ссылке»

> **Обновление 08.11.2026 — проверено по документации; вариант C ниже устарел.**
> - **Cloudflare Pages не подходит:** с 9 июня 2025 российские провайдеры режут трафик к сайтам за Cloudflare примерно до 16 КБ на соединение. Наш сайт весит несколько мегабайт (один index.html ≈ 1,2 МБ) — в России без VPN он не загрузится.
> - **Netlify бесплатно — без пароля:** на Free и Personal «private» видит только владелец команды, поэтому для неё сайт пришлось бы сделать public — это тот же «доступ по ссылке», что и сейчас. Пароль — только на Pro. Каждая выкладка на прод — 15 кредитов; у новых команд (с 28.07.2026) проекты по умолчанию private. Открывается ли netlify.app у её провайдера — не проверено.
> - **GitHub Pages из приватного репозитория** — только с GitHub Pro (или Team / Enterprise), и сам сайт всё равно публичный: скрыт только репозиторий.
> - **Вывод:** остаёмся на GitHub Pages (`emoorpheus.github.io/abibyan/`, у тебя на iPhone 17 открывается): «по ссылке» + noindex. Если личные записки надо спрятать даже от тех, у кого есть ссылка, — шифровать их в самой игре фразой, которую знает только она.

**Да, так можно.** Сайт открывается у того, у кого есть ссылка (QR на открытке), а больше его никто не найдёт.

Что уже сделано в самой игре: на каждой странице стоит `<meta name="robots" content="noindex, nofollow">` — Google, Яндекс
и другие поисковики его **не показывают в поиске**. Ссылок на него нигде нет. Значит, найти сайт может только тот, кто знает адрес.

Одно но: «по ссылке» значит без пароля — у кого ссылка, тот и откроет. Для подарка так и нужно: Даше не надо ничего вводить.

## Что выбрать

| Как | Сайт | Файлы (и твои записки внутри) | Деньги | Адрес |
|---|---|---|---|---|
| **A. GitHub Pages, репозиторий Public** (как в `GITHUB_PAGES.md`) | по ссылке, не в поиске | видны всем, кто зайдёт в твой профиль GitHub | бесплатно | `emoorpheus.github.io/abibyan/` |
| **B. GitHub Pages, приватный репозиторий (Private)** | по ссылке, не в поиске | скрыты | GitHub Pro, около $4 в месяц | `emoorpheus.github.io/abibyan/` |
| **C. Netlify или Cloudflare Pages + приватный (Private) репозиторий `abibyan`** | по ссылке, не в поиске | скрыты | бесплатно | `abibyan.netlify.app` или `abibyan.pages.dev` (если имя свободно) |

**Советую C, если хочешь бесплатно и чтобы записки никто не прочитал. Если адрес на github.io важнее — тогда B.**
A подходит, только если тебе всё равно, что файлы игры (с текстами записок) лежат открыто.

Адрес на открытке должен совпадать с настоящим. Выберешь C (или другое имя) — скажи адрес, и я перепечатаю QR:
`python3 tools/card.py https://abibyan.netlify.app/` (строка и QR на обороте обновятся).

## B. GitHub Pages + приватный репозиторий
1. Купи **GitHub Pro**: github.com → аватар → Settings → Billing and plans → Upgrade.
2. Репозиторий `abibyan` → Settings → General → внизу **Change visibility → Private**.
3. Settings → Pages — должно остаться «Your site is live at …/abibyan/». Всё остальное — как в `GITHUB_PAGES.md`.

## C1. Netlify (проще всего, ~3 минуты)
1. Зайди на **app.netlify.com** (бесплатный аккаунт, можно через GitHub). Без входа сайт со временем удалится — нужен вход.
2. Вариант «перетащить»: **Add new site → Deploy manually** → перетащи в окно **папку** с распакованным
   `dist/moy-abibyan-site.zip` (`index.html` и `test.html` там прямо сверху).
   Вариант «из GitHub»: **Add new site → Import an existing project → GitHub → `abibyan`** (Private подходит), Build command — пусто,
   Publish directory — папка, где лежит `index.html` → Deploy.
3. **Site configuration → Change site name** → например `abibyan` (или своё, если занято) → адрес `https://abibyan.netlify.app/`.
4. Обновить потом: Deploys → перетащить новую папку (или просто загрузить новые файлы в GitHub — Netlify обновит сам).

## C2. Cloudflare Pages (тоже бесплатно)
1. **dash.cloudflare.com** → Workers & Pages → **Create → Pages**.
2. **Upload assets** (перетащить папку из `dist/moy-abibyan-site.zip`) или **Connect to Git** → `abibyan` (Private подходит),
   без сборки, папка с `index.html`.
3. Имя проекта `abibyan` → адрес `https://abibyan.pages.dev/`.

## Общее
- Везде `https://` — значит работают микрофон (свечки) и «На экран „Домой“».
- Тестовая версия лежит рядом: `…/test.html` (репетиция 21.11). Её адрес знаешь только ты.
- **Не отправляй ссылку никому, кроме неё**, и не публикуй открытку с QR в соцсетях — это и есть «по ссылке».
- Пароль на сайт тоже можно поставить (Netlify — платно, Cloudflare Access — бесплатно, но с кодом на почту).
  Для подарка не советую: лишний шаг для неё, и с иконки на телефоне он неудобен.
