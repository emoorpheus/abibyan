# Round 22 «Подарок для Дашулика» — дизайн (2026-11-05)

Для кого: Даша («Дашулик»), 24 года 21.11.2026; игра — подарок от парня в честь её плюшевой обезьянки. Владелец выбрал: 1 распаковка,
2 торт с 24 свечками (если микрофон реально сработает), 4 скелет «24 секретов» (тексты пришлёт он), 9 открытка с QR + GitHub Pages.
Решения (сам, без вопросов):
- **Одна игра.** Первый запуск — коробка вместо окна имени (имя Абибян, его не спрашиваем). Тап по коробке ×3 или «Открыть» (#nm-ok).
- **Праздник по дате:** 21.11 каждый год, а если она не заходила — первый заход до 28.11. Свечей = 24 + (год − 2026).
  В день праздника зал украшен (флажки, «ДАШУЛИК», шары «24»), на следующий день украшения уходят; остаются фото в альбоме
  (не вытесняется), 3 торта в холодильнике, «24 секрета» и праздник каждый год.
- **Задувание:** кнопка «Подуть» → микрофон без шумодава/АРУ/эхоподавления, анализ каждого кадра: громкость выше порога (≥0.03 и ×4
  шумового фона) + НЕ периодичный звук (автокорреляция разности < 0.45: речь и музыка периодичны, дутьё — шум) + держится ≥0.12 с.
  Сила → скорость гашения (5…30 свечей/с). Пламя клонится от уровня звука (видно, что микрофон слышит). Нет микрофона/запрет/не
  выходит — «Задуть пальцем» (провести по свечкам), всегда доступно. Во время слушания музыка молчит, звук гашения — тональный.
- **24 секрета:** 24 места в 5 комнатах, слоты {место, день, текст, картинка}; пустые тексты не прячутся (до его текстов в игре их
  нет; в тестовой версии — образцы, все сразу). По умолчанию 8 в первый день, потом по 2 в день (тянется после ДР). Альбом → вкладка
  «Сердечки». Шаблон для него: docs/24-secrets.md.
- **Сайт:** dist/site уже годится для GitHub Pages (относительные пути, .nojekyll); тест — раздача из подпапки /abibyan/.
  Ссылка: https://emoorpheus.github.io/abibyan/ (выкладывает он сам, мы не публикуем). Открытка: tools/card.py → PDF + PNG с QR.
- Предпросмотр праздника — только тестовая версия: `abibyan-test.html#bday` (или `#bday=2027`).
