# Round 20 — «Телефон-ready ч.2»: звук с первого касания, батарея, iPhone

**Цель:** на телефоне (особенно iPhone) звук есть с первого же касания, игра не жжёт батарею, пока он просто сидит дома,
сохранение на iPhone не пропадает, а голос можно сделать легче — но только после того, как владелец послушает A/B.

**Что уже было (аудит):** safe-area, touch-action/user-select/callout, contextmenu, `interrupted` → resume, AUDIO.init на pointerdown,
visibilitychange → save + пауза + ac.suspend, pagehide save, storage.persist, maximum-scale=1, tap-highlight прозрачный.

**Найдено:**
- По спецификации (и в Chrome/Safari) касание пальцем активирует страницу только на `pointerup`/`touchend`, не на `pointerdown`.
  AudioContext создаётся на pointerdown первого касания «спящим», а будит его только второе касание → первое касание без звука.
- Главный цикл рисует 60 кадров/с всегда: дома, когда он просто сидит или спит, это ~39 % CPU на среднем телефоне (×4) — батарея.
- iPhone Safari (не «На экран Домой») стирает localStorage сайта, если не заходить 7 дней (ITP) — нигде не сказано.
- Голос — 10 МБ base64 MP3 (40k фразы / 32k слова); можно легче, но владелец уже говорил, что ниже — хуже разборчивость → только A/B.

**Архитектура:**
- `AUDIO.init` ещё и на `pointerup`/`touchend`/`click` (capture). Первое пробуждение проигрывает 1 тихий сэмпл (старые iOS). Режим
  `navigator.audioSession` не трогаем: «playback» глушил бы музыку игрока и игнорировал бы бесшумный режим; вместо этого в настройках на iOS —
  подсказка «нет звука — выключи „Бесшумно“».
- Кадры: `APP` считает нужный fps — 60 в мини-игре, 2,5 с после любого касания/клавиши, при переходе между комнатами, походе, прыжке,
  гостях, движении камеры; иначе дома 30, во сне 15. Лишние vsync пропускаются (step не зовётся), dt до 0,1 с при пониженной частоте.
  `advanceTime` (тесты) не меняется. `APP.fps()` → {target, renders} для тестов. На 120 Гц экранах тоже не больше 60.
- iPhone: `UI.plat()` → {ios, standalone, web}. Safari по http(s), не установлена → один раз тост «Поделиться → На экран „Домой“…»
  (флаг `s.hint.ios` в сохранении), и строчка в настройках.
- CSS: `overscroll-behavior:none` на html/body (iOS 16+ без «резинки»).
- tools/compat.js: сканер src/*.js (кроме банка голоса) и style.css на то, чего нет в Safari 15 (lookbehind, structuredClone,
  Object.hasOwn, .at(), findLast, requestIdleCallback, OffscreenCanvas, ctx.filter/roundRect/letterSpacing, :has, dvh, @container,
  color-mix, CSS nesting) — 0 находок. Память канвасов после обхода всех комнат и игр — далеко от лимита iOS (~256–384 МБ), ни одного
  канваса больше 4096×4096.
- Голос A/B: tools/voice_ab.py перекодирует из кэша TTS (сырые .npy → тот же finish/EQ → MP3) 3 варианта: A — как сейчас (40k/32k),
  B — 32k/24k, C — 24k/20k; dist/abibyan-voice-ab.html: фразы и слова, кнопки A/B/C, «вслепую», вес банка для каждого варианта.
  В игре голос НЕ меняется, пока владелец не выберет.
