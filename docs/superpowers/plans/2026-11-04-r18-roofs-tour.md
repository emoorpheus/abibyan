# R18 — Мини-игры 2.0: «Крыши» и турнир недели

Цель: одна большая игра с районами и недельный турнир с друзьями (таблица, призы). Тест: test/r18.js (пишется первым, красный → код → зелёный), шаг r18 в test/all.sh.

## «Крыши» (games.js, id `roofs`, телефон, этап «Детёныш», ×2 монеты)
Суть: Абибян бежит по крышам города, который видно с балкона. Одна кнопка: тап — прыжок, держи — выше, тап в воздухе — кувырок (второй прыжок, один на полёт).
- Опасности: просвет между домами (падение → −♥, шарик поднимает на следующую крышу), трубы/вентиляция (удар сбоку → −♥, отскок), бельё на верёвке над частью просветов (удар головой → запутался и падает) — наказывает «жать всё время» и «всегда держать».
- Районы по 3 уровня: «Наш двор» (1–3: просветы, трубы) → «Старый город» (4–6: + тенты-батуты, бельё) → «Стройка» (7–9: + балки крана над широкими просветами) → «Набережная» (10–12: + антенны, широкие просветы на кувырок) → «Центр» (13+: стекло, ночь, всё вместе). Новый район — надпись «Новый район: …», свой цвет неба, дома и дальний силуэт телевышки (та самая мачта с балкона) ближе с каждым районом.
- Очки: бананы (10 = 1 монета), золотой банан высоко = 1 монета, «Впритык!» (приземление у самого края после просвета) = +2 банана; уровень — coinsFor × 2.
- Скорость 82 + 10·√(L−1). Генератор с сидом, проверки: каждый простой просвет ≤ 0,85 дальности прыжка, широкий — ≤ 0,8 кувырка или с балкой, подъём ≤ 0,6 высоты прыжка (выше — только с тентом), бельё только над просветами, которые берутся коротким прыжком.
- Инварианты (тест): без нажатий — проигрыш на 1-м уровне; «жать без остановки» хуже умного бота (теряет ♥ на бельё с района 2); умный бот проходит уровни 1, 4, 7, 10, 13; районы меняются на 4/7/10/13.

## Турнир недели (src/tour.js, TOUR)
- Неделя пн–вс; игра недели — по кругу из доступных ему (catch, roofs, stack, bongo, vine, balloon, gym, super, race).
- Друзья: итог недели каждого = рекорд Абибяна в этой игре (≥ 3) × коэффициент (лидер 0,95–1,2, остальные 0,5–0,95; любимая игра друга +0,15); в течение недели счёт растёт (к пятнице — итог).
- Его счёт — лучший уровень в этой игре за неделю. После игры в окне итогов строка «Турнир недели: N-е место», тост «Ты обогнал …!».
- Вкладка «Турнир» в «Мини-игры»: игра недели, «осталось N дн.», таблица 5 мест с портретами и призами, кнопка «Играть».
- Итоги в понедельник (при первом входе дома): окно «Итоги турнира» — место, приз 100/50/30/15/10 монет (если играл), за 1-е место — кубок (счётчик побед, достижение «Чемпион недели»), фото «Чемпион недели» в альбом, его реплика.
