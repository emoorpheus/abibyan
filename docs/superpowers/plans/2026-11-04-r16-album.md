# Round 16 (plan R16): Альбом и карта приколов

Goal (roadmap R16): auto-photos of bright moments + the «Фото» button opens the album page; a map of found gags by room
(found → a colour crop of the room + its name, not found → a dark silhouette «?»).

## Design
- New module `src/album.js` (ALBUM), built after `gags` (build.py order).
- Storage: photos live under their own localStorage key (`<save key>_album`) — the main save stays small (no dataURLs);
  moment flags `S.moments = { dance: 1, 'grow:3': 1, … }` are in the save. Reset clears both.
- Entry: `{ id, k (moment id or 'photo'), title, cap, sub, d (ms), src (150×150 PNG dataURL of the room at that moment) }`.
  Cap: 36 entries; when full the oldest plain photo goes first, then the oldest moment.
- `HOME.photo()` (manual / party) composes the polaroid as before and also adds the entry (k 'photo' / o.k).
- `ALBUM.moment(id, o)` — once per id: a quiet shutter, small flash, toast «Фото в альбом: …», no modal, doesn't count «Фотограф».
  Moments: `dance` (first dance), `grow:<stage>` (new growth stage, after the «подрос» card), `skuf` (became Скуф),
  `friend:<id>` (first visit of each friend), `party` (first «Все вместе» photo), `heist` (first successful «Вылазка»).
- UI: zal «Фото» → sheet «Альбом» with tabs «Фото» (button «Сделать фото» + grid of polaroid thumbs, newest first;
  a tap → the big polaroid with «Сохранить» / «Закрыть») and «Приколы» (Найдено N из M; per room a grid of cells:
  found = crop of ROOMS.build(room) around the gag rect + name, not found = silhouette + «?»).
- Gag places: GAGS.map() → { room: [{ id, r: rect | fallback }] }; mark(id, room) also records `seen` per room
  (`gags.where['room:id']`) so the shared «window» is counted per room.
