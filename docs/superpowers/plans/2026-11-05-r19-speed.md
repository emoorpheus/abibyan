# Round 19 — «Лёгкий и быстрый»: голос не мешает запуску

**Цель:** игра открывается быстро и на слабом телефоне, сайт не качает 11 МБ до первого кадра, интерфейс игр не дёргает DOM каждый кадр.

**Замер до (tools/perf.js base, test/look/r19_perf_base.json):** первый кадр — 899 мс (CPU ×1) / 3352 мс (CPU ×4, средний телефон);
самая длинная задача 1,8 с; без голосового банка — 338 / 817 мс. Голос (speech.js 8,3 МБ + voice_rec.js 1,9 МБ, base64 MP3) — это ~2,5 с
из 3,4 с запуска: V8 разбирает его как JS-литерал (и JSON.parse ещё хуже — 4,2 с). Тишина в клипах ≈ задержка MP3-кодека (обрезать нечего),
Xing-заголовков нет; качество (битрейт) не трогаем — владелец уже говорил, что ниже хуже разборчивость.

**Архитектура:**
- src/speech.js и src/voice_rec.js остаются источником (tools/tts.py, tts_add.py, rec.py не меняются). build.py превращает банк в простой
  текст: `@раздел` и строки `ключ\tполе\tполе…` (fx — по строке на вариант). Группа 1 — lines, fx, rec (нужны в обычной игре), группа 2 —
  words, syl (набранный текст «Повторюшки», имена).
- Один файл (abibyan.html, index.html, abibyan-test.html): главный скрипт с пустым `SPEECH` → первый кадр; дальше инертные блоки
  `<script type="text/plain" class="vb" data-g="1|2">` по ≤256 КБ (парсер успевает отдавать кадры между ними), после каждой группы —
  `AUDIO.voiceInline(g)`: разбирает блоки в SPEECH (подстроки, без копий), удаляет их из DOM, ставит `SPEECH.ready |= g`.
- Сайт (dist/site): index.html без голоса (~1 МБ) + voice1.txt, voice2.txt; `window.ABI_VOICE = 'files'` → audio.js сразу качает их
  fetch'ем (gzip на хостинге), service worker кладёт их в кэш при установке → офлайн голос тоже есть.
- AUDIO.say до прихода голоса: запоминается и звучит, когда группа 1 пришла (если ждали ≤1,5 с); пузырь — сразу, как раньше.
- UI.gameHudSet пишет в DOM только изменившееся (уровень, монеты, полоска).
